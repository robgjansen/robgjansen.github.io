Internet Censorship Circumvention

How can we design technology that disrupts censorship and promotes free and open communication on the internet?

Censors around the world seek to block internet access to otherwise open information and to software tools that are used to privately communicate with others online. I seek to develop technologies to disrupt network censorship and to empower people to use the internet to safely and privately access open information and communicate with others.

Encrypted Traffic Analysis

What can we learn from encrypted network traffic patterns and how can we protect against encrypted traffic analysis?

Encryption is a foundational building block upon which we rely to provide security and privacy in our increasingly digital lives. However, even encrypted communication can reveal sensitive information about your internet usage. I seek to understand the extent to which the patterns of encrypted network communication leak private information, and to develop techniques to thwart encrypted traffic analysis.

Privacy-Preserving Network Measurement

How can we conduct measurements of internet communication systems without invading the privacy of the systems' users?

It is important to be able to measure internet communication systems in order to diagnose problems, to understand newly deployed enhancements, and to gauge system scalability and impact. However, such measurements should not erode the privacy of the systems' users. I seek to develop privacy-preserving measurement systems and apply them to safely understand real-world communication systems.

Network and Distributed System Simulation

How can we run real, unmodified applications in a network simulation environment while meeting high performance requirements?

Network experimentation tools are vitally important to the process of developing, evaluating, and testing privacy-preserving networks and other distributed systems. However, large distributed systems impose efficiency and scalability challenges that are not adequately addressed with traditional architectures. I seek to develop innovative techniques for running real applications in simulated network environments while meeting the high performance requirements of large distributed systems.

Overlay Network Performance Analysis

Which technologies can improve performance in overlay networks and how can we analyze and compare performance trade-offs?

Privacy-preserving networks such as Tor protect users' internet traffic by routing it through an overlay network of multiple proxy nodes that relay the traffic to the intended destination. The extended path length and proxy node resource constraints means that overlay networks are more performance sensitive than traditional networks. I seek to design privacy-preserving performance enhancements for overlay networks and frameworks to help us measure and analyze performance-enhancing algorithms.

RECENT PUBLICATIONS

  1. Rob Jansen, Ryan Wails, and Aaron Johnson:
    A Measurement of Genuine Tor Traces for Realistic Website Fingerprinting. Passive and Active Measurement Conference, 2026. See associated technical report.
    pdf abs bib details

    Website fingerprinting (WF) enables an adversary to predict the website a user is visiting, despite the use of encryption or Tor. Previous work almost exclusively uses synthetic datasets to evaluate the success of WF attacks. We present GTT23, the first dataset of genuine Tor traces, intended especially for WF analysis. We obtain it through a measurement of the Tor network, and, with 1.4 ×10^7 traces, it is larger than any existing WF dataset by an order of magnitude. We survey 28 WF datasets published since 2008 and compare them to GTT23, discovering common deficiencies of synthetic datasets for drawing conclusions about the WF effectiveness. We have made GTT23 available to other researchers.

  2. Rob Jansen:
    CellShift: RTT-Aware Trace Transduction for Real-World Website Fingerprinting. Network and Distributed System Security Symposium, 2026.
    pdf abs bib details

    Website fingerprinting is a privacy attack in which an adversary applies machine learning to predict the website a user visits through Tor. Recent work proposes evaluating WF attacks using the "genuine" patterns or traces of Tor users’ natural interactions that can be measured by Tor exit relays, but these traces do not accurately reflect the patterns that an entry-side WF attacker would observe. In this paper, we present new methods for transducing exit traces into entry traces that we can use to more accurately estimate the risk WF poses to real Tor users. Our methods leverage trace timestamps and metadata to extract multiple round-trip time estimates and use them to "shift" traces to the perspective of a target vantage point. We show through extensive evaluation that our methods outperform the state of the art across multiple synthetic and genuine datasets and are considerably more efficient; they enable researchers to more accurately represent the real-world challenge facing an entry-side WF adversary, and produce augmented datasets that allow an adversary to boost the performance of existing WF attacks.
